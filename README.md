# 🚦 BRTA Traffic Sign Quiz

A free, offline-friendly quiz and study tool covering all **118 official traffic signs** from the Bangladesh Road Transport Authority (BRTA) chart — built for anyone preparing for the BRTA driving license exam.

**🔗 Live site: [REPLACE_WITH_YOUR_PAGES_URL](REPLACE_WITH_YOUR_PAGES_URL)**

![quiz screenshot placeholder](screenshot.png)

## Features

- **Quiz mode** — see a sign image, pick its meaning from four Bengali options. Filter by category (prohibitory, mandatory, warning, information) and question count. Keyboard shortcuts (`1`–`4` to answer, `Enter` for next). Ends with a score and a review of everything you missed.
- **Study mode** — browse all 118 signs in the chart's original order, filter by category, tap a sign to enlarge it, and optionally hide the captions to test yourself before revealing them.
- **100% accurate depictions** — every sign and caption is cropped directly from the official BRTA chart at high resolution, not redrawn or retyped.
- **No install, no login, no tracking** — a single self-contained HTML file. Works fully offline once loaded.

## Why this exists

The official BRTA sign chart is a static image/PDF — fine for printing, hard to actually study from. This turns it into something you can quiz yourself on repeatedly, on any phone or computer, for free.

## Usage

Just open the [live site](REPLACE_WITH_YOUR_PAGES_URL), or download `index.html` from this repo and open it in any browser — no server required.

## Tech

Plain HTML, CSS, and JavaScript. No frameworks, no build step, no external dependencies or network calls. Sign and caption images are embedded directly in the page as base64 PNGs.

## Source
